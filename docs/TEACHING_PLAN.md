# 3jsBridge 桥梁交互教学方案

版本：v0.2 · 更新日期：2026-10-11 · 状态：课程规划，待教学试点与知识审校

本方案在五阶段初步规划上细化教学模块、交互活动、学习成果和实施顺序，供教学内容负责人、桥梁知识审校人及开发者共同使用。项目通过 Three.js 帮助学习者观察桥梁、解释构件关系、分析案例和表达判断；先做好一节能验证学习效果的课，再逐步扩展课程。

五个阶段保持为：**知识入门、知识深化、专业进阶、业务菁英、大师成就**。名称表示学习进程，不代表职业资格、岗位授权或工程能力认证。所有模型、受力箭头、变形、施工及监测情境均为教学用途；不得据此进行工程设计、验算、施工指挥或实桥安全鉴定。

配套文档：[技术方案与项目管理规范](TECHNICAL_PLAN.md)、[开发说明](DEVELOPMENT.md)、[项目说明](../README.md)。本文件回答“教什么、怎样学、用什么证明学会”；技术方案回答“如何实现与验证”。

## 1 适用对象与学习路径

### 1.1 默认学习者与教学方式

建议首批面向桥梁兴趣学习者、土木相关学生及初入行业人员。正式备课前仍需确认年龄段、已有力学基础、班级规模、设备与课堂时长。兴趣学习者可完成前两阶段及后续精选案例；相关专业学习者可继续完成全过程。进阶内容提供必要概念补充，不默认学习者已修完结构力学。

- **自主学习**：短讲解、操作提示、分层反馈与订正记录，允许反复回看。
- **教师带领**：先全班预测，再分组操作与讨论；教师集中处理同类误解。
- **小组研讨**：同组分担观察、证据记录和质询，个人仍须独立解释关键结论。
- **已有基础者**：通过诊断题与陌生案例说明进入相应阶段；不能仅凭自评或跳过动画获得阶段完成记录。

每阶段建议安排 5 个模块。基础模块可按 20–35 分钟、进阶案例模块按 35–60 分钟起草教案，阶段项目另行安排。这些仅是备课估算，不是学习达标时限；试教后按阅读、操作和讨论负担调整，不用限时操作考核桥梁知识。

### 1.2 五阶段目标与衔接

| 阶段 | 核心问题 | 可观察的学习结果 | 进入下一阶段的主要证据 |
| --- | --- | --- | --- |
| S1 知识入门 | 我看到的是哪类桥，各部分做什么？ | 识别、定位、用日常语言描述 | 陌生桥介绍卡及构件说明 |
| S2 知识深化 | 作用如何传递，为什么出现这些现象？ | 预测、解释、指出模型条件 | 带传力路径的讲解与修订记录 |
| S3 专业进阶 | 构造、施工和运营如何联系？ | 对图、排序、记录与辨析证据 | 构造施工案例及虚拟巡检记录 |
| S4 业务菁英 | 信息不完整时，怎样比较并提出建议？ | 比较备选、说明取舍、核实冲突 | 模拟建议书及答辩 |
| S5 大师成就 | 条件改变后，怎样迁移并教会别人？ | 重建论证、组织知识、回应质询 | 综合案例包与可复用微课 |

阶段关系是能力递进，不是一次性看完所有模块的硬性门禁。教师可以根据诊断结果补学指定模块；任何阶段都应能返回术语、基础构件与证据记录练习。

### 1.3 跨阶段主线与案例组织

建议以一座**虚构教学梁桥 A**贯穿前三阶段，再以桥型对比组 B 和综合情境 C 扩展。案例名称、几何、图纸、照片及数据均标明来源与教学改编范围；虚构数据显式注明，避免被误认为真实监测记录。

主线一是“桥面上的作用怎样传到下部结构和地基”，主线二是“构件如何在建造与使用过程中发挥作用”。以支座为例：S1 找位置与作用 → S2 理解约束和允许的变形 → S3 对照构造与可见异常 → S4 结合多源材料提出核实和养护讨论次序 → S5 在条件变化后重新解释建议的适用边界。不同桥型并非都有相同的支承构造，迁移任务必须让学习者检查前提。

案例按难度增加信息，而不是每次换一座更复杂的模型：先呈现明确构件，再增加连接关系、施工状态、运营资料与证据冲突。各阶段作品可继续修订，保留“原判断—新增证据—改变之处”的记录。

## 2 S1 知识入门

**阶段目标**：看懂一座桥的用途、主要构件与基本桥型，能够说明自己看到什么、还不能确定什么。知识范围参考同济桥梁课程及教材目录 [1][2]。

**前置与诊断**：不要求专业知识。先尝试找到桥面和桥墩、回到整体视角，并区分桥上交通方向与桥下跨越对象。不会操作者先做界面练习；术语困难者使用图例与日常语言释义，操作熟练度不计入知识评价。

### S1-M01 桥梁与跨越场景

- **目标与内容**：描述跨河、跨路、跨谷等跨越需求，识别桥上与桥下的使用者；认识通行需求、周边环境与桥梁布局的联系。
- **误解提示**：桥的用途不能仅由外形决定；高大、复杂或漂亮不自动等于“更适合”。
- **任务顺序**：观察场景 → 标出要跨越的障碍及通行方向 → 预测需要保留的空间 → 切换视角核对 → 用两句话解释场景需求。
- **学习证据**：一张场景标注图，至少区分“画面可见信息”和“需要询问的信息”。看不出场景时允许选择“不确定”并说明缺什么。

### S1-M02 构件的名称与作用

- **目标与内容**：在完整教学模型中定位桥面系、主梁、桥墩、桥台、基础及所选案例的支座，说明上部结构与下部结构的基本关系。
- **误解提示**：桥面与主梁不能一概视为同一构件；桥墩和桥台作用与位置有区别；地下基础可能不可见。
- **任务顺序**：整体找构件 → 按名称点选 → 隔离或看分层图 → 将名称与作用配对 → 恢复整体并说明相邻构件关系。
- **学习证据**：独立标注本课指定的主要构件，并说明其中两个构件的作用。基础或支座需模型补充后才能正式考核，不能让当前方块小样承担缺失构造的教学。

### S1-M03 五类桥型的观察方法

- **目标与内容**：从主要承重结构及连接特征观察梁桥、拱桥、刚构桥、斜拉桥和悬索桥；用桥面、梁、拱、塔、索等线索比较。
- **误解提示**：有索不一定就是悬索桥；桥面形状和装饰不能独立决定桥型；所列为本课重点，并非穷尽所有分类及组合体系。
- **任务顺序**：观察无标签模型 → 提出候选桥型 → 找两项结构线索 → 与相似桥型并排比较 → 给出判断或说明现有画面不足。
- **学习证据**：桥型对比卡，写出至少一组容易混淆的桥型及其辨别依据，避免只背剪影。

### S1-M04 空间术语与材料

- **目标与内容**：在给定示意图上区分跨径、桥长、桥高和净空，辨认纵向、横向、立面与横断面；认识混凝土、钢材和组合结构的入门概念。
- **误解提示**：全桥长度与单跨跨径不同；净空需要指明位置与方向；模型颜色是教学编码，不能直接证明真实材料。
- **任务顺序**：选视角 → 预测术语对应范围 → 显示审校过的标注 → 对照材料说明 → 在新图上重新标注。
- **学习证据**：完成术语指认和一条材料说明。教学模型不提供无依据的精确尺寸，标注以定义和示意范围为主。

### S1-M05 一座桥的生命周期

- **目标与内容**：认识规划、设计、建造、运营、检查和养护的关联，知道桥梁需要持续管理，能把构件知识用于一段完整介绍。
- **误解提示**：建成通车不是工作结束；看起来完好不等于已获得安全结论。
- **任务顺序**：排序生命周期卡片 → 把构件放入相应观察任务 → 看一座未练习过的示例桥 → 制作介绍卡 → 根据同伴提问修订。
- **学习证据**：介绍卡包含用途、桥型依据、主要构件和一项待确认信息。

**阶段项目与出口**：提交陌生桥介绍卡及简短口头或文字说明。指定主要构件无关键混淆，桥型判断有结构线索，术语能结合图示使用；仅猜对名称不通过。若混淆桥面/主梁回到 M02，桥型混淆回到 M03，空间术语混淆回到 M04；完成订正后换一个相似但未练习过的案例重试。达到以上条件后进入 S2。

## 3 S2 知识深化

**阶段目标**：把构件、材料与作用联系起来，解释基本传力过程，区分现象、原因假设与验证条件。知识范围参考 [1][2]。

**前置与诊断**：能完成 S1 构件与桥型说明。用一个受压、一段受拉和一根受弯的日常示例检查力学直觉；必要时补充箭头含义、方向和约束的入门练习。本阶段不以公式推导或数值计算作为目标。

### S2-M01 作用与可见响应

- **目标与内容**：区分结构自重、车辆、风、温度、地震等作用概念，认识作用位置、方向及变化方式可能影响响应。
- **误解提示**：所有作用并非都能简单画成向下的重量；变形动画的大小不能读成真实响应数值。
- **任务顺序**：选择单一作用情境 → 先画预测箭头 → 播放或逐帧查看概念示意 → 比较预测 → 写出此次只改变了什么。
- **学习证据**：预测与解释对照表，能区分施加的作用和观察到的响应，并指出没有展示的因素。

### S2-M02 拉压弯剪扭的直观辨认

- **目标与内容**：通过受控简化构件认识拉、压、弯、剪、扭，理解实际构件可能同时出现多种受力效应。
- **误解提示**：每个构件不必只对应一种受力；外观变化明显与否不能用于直接判断危险程度。
- **任务顺序**：预测变形特征 → 切换单一演示 → 用文字描述相对运动 → 给所选桥梁构件匹配可能的效应 → 解释模型简化。
- **学习证据**：完成两项易混淆效应的对比说明。反馈强调判断依据，避免把颜色与术语机械绑定。

### S2-M03 连起传力路径

- **目标与内容**：以梁桥教学案例建立桥面、主梁、支座、墩台、基础及地基之间的概念联系，再比较拱与索体系的不同路径。
- **误解提示**：传力不会在桥墩处凭空结束；一条演示箭头不是全部空间受力状态；不同体系不能照抄同一路径。
- **任务顺序**：给定作用位置 → 按构件连接路径 → 逐段检查承接关系 → 对照解释反馈 → 更换桥型并说明哪些环节改变。
- **学习证据**：一条能逐段说明理由的完整路径，以及一项桥型间差异。遗漏承接环节时，先回看对应构件，再重新连线。

### S2-M04 支承约束与变形

- **目标与内容**：认识支承如何传递作用、限制或允许某些运动，比较经审校的简化支承情境；初步讨论变形与稳定问题。
- **误解提示**：允许某方向运动并非构件失效；变形存在不等于失稳；任意取消支承的动画不能代替工程结论。
- **任务顺序**：指出支座位置 → 预测给定方向是否允许移动 → 切换一个约束条件 → 对照运动示意 → 解释改变条件后原结论能否沿用。
- **学习证据**：支承条件、预测和解释三联记录，注明本例不代表所有支座形式；不给出实际支座选型或安全判定。

### S2-M05 材料与耐久性线索

- **目标与内容**：认识材料特性与裂缝、腐蚀、疲劳等问题的概念联系，学习从观察提出多个可能原因。
- **误解提示**：看到裂缝不能直接宣布失效；没看到损伤也不能证明安全；替换模型材质不意味着已模拟材料行为。
- **任务顺序**：读案例条件 → 标出可见现象 → 提出可能解释 → 请求时间、环境或检查资料 → 写明现有证据能支持到哪一步。
- **学习证据**：一份“现象—假设—需要补证”的记录，至少保留一种待排除的解释。

**阶段项目与出口**：制作一个带传力标注的模型讲解，包含作用、路径、支承条件与简化边界，再对一个条件变化作预测。要求路径连贯，能解释构件关系，能说明动画无法证明什么。路径断裂回到 M03，约束混淆回到 M04，把表面现象当结论回到 M05；订正后用新作用位置重试。通过后进入 S3 的图示和过程分析。

## 4 S3 专业进阶

**阶段目标**：把图示、构造、施工阶段和运营观察联系起来，形成可复核的学习记录。知识范围参考 [1][2][3]。

**前置与诊断**：能解释一条传力路径和模型条件。先完成三维构件与二维图上位置的配对；对图困难者补学 S1-M04，不以复杂制图符号记忆作为门槛。

### S3-M01 从图示找到三维构件

- **目标与内容**：对应立面、横断面与局部节点示意，理解同一构件在不同视图中的位置和邻接关系。
- **误解提示**：剖面中没有显示的构件不一定不存在；模型可见表面并不能替代节点内部构造信息。
- **任务顺序**：读方向图例 → 在二维图选位置 → 三维聚焦并核对 → 切到相邻断面 → 解释两图为何不同。
- **学习证据**：三组图模对应标注及一处易误读位置的解释；只提供审校过的示意图，不冒充施工图交底。

### S3-M02 比较桥型与构造

- **目标与内容**：围绕跨越条件、结构组成和建造可达性，比较梁、拱、刚构及索体系案例，区分共同功能与构造差异。
- **误解提示**：某桥型在一个案例中适用，不代表相同外观或单一跨越条件下必然最优。
- **任务顺序**：阅读两个案例条件 → 标共同功能 → 找构造差异 → 关联条件与差异 → 写出不能直接类推的部分。
- **学习证据**：比较表至少包含构造依据和适用前提；资料不足时提出问题，允许多种有条件的解释。

### S3-M03 施工阶段与临时状态

- **目标与内容**：认识现浇、预制架设、悬臂施工的基本过程，理解施工阶段与成桥状态不同，关注临时支承和顺序。
- **误解提示**：拆解动画倒放不等于施工过程；成桥能工作不证明任意中间状态都成立。
- **任务顺序**：观察审校过的关键帧 → 预测下一步 → 排序并指出临时设施 → 比较一组错误顺序 → 解释缺少的条件。
- **学习证据**：带理由的阶段序列和一处关键临时状态说明。动画只覆盖选定工法案例，不提供实桥施工操作指令。

### S3-M04 从细部到运营问题

- **目标与内容**：认识桥面防排水、伸缩缝、支座等细部功能，讨论局部现象与相邻构件、环境之间的可能联系。
- **误解提示**：一处可见病害不一定只有一个原因；位置接近不等于已证明因果关系。
- **任务顺序**：定位细部 → 回顾其正常功能 → 查看异常示例 → 沿相邻关系寻找补充线索 → 写出观察与推测的区别。
- **学习证据**：细部观察卡，包含构件 ID、位置、现象、资料来源和待核实问题，不填写未经依据支持的安全等级。

### S3-M05 虚拟巡检与资料记录

- **目标与内容**：区分巡视、检测、监测、养护与资料管理的作用，形成位置明确、现象客观、来源可追溯的观察记录。
- **误解提示**：一张截图不足以完成专业检测；监测曲线异常不自动等于结构异常；虚拟巡检不替代现场工作。
- **任务顺序**：阅读任务与资料范围 → 按路线观察 → 标注发现及未覆盖区域 → 记录时间/视角/来源 → 与另一份记录交叉检查。
- **学习证据**：虚拟巡检学习记录，包含原始观察、原因假设、缺失资料与下一步核实需求，能让同伴按记录找到同一位置。

**阶段项目与出口**：完成一个“构造—施工—运营”案例说明及虚拟巡检记录。要求图模映射可复核，施工排序能解释临时状态，运营记录区分事实与推测，承认未观察区域。图模错位回到 M01，顺序背诵却不能解释回到 M03，证据表述越界回到 M04–M05；换一个局部案例重试。完成后进入 S4 的约束与多源信息讨论。

## 5 S4 业务菁英

**阶段目标**：在模拟业务情境中整合需求和证据，比较备选方案，提出有限度、有依据、可沟通的建议。生命周期及监测议题参考 [3][4]；具体活动为教学设计。

**前置与诊断**：能提交可复核观察记录，区分现象、推测与结论。入口任务给出两份互相矛盾的资料，检查学习者是否先核实来源与条件，而不是立即选边。

### S4-M01 把需求转为比较条件

- **目标与内容**：识别通航、交通、地形、地质、环境、施工条件等需求，区分已知约束、利益偏好和待确认信息。
- **误解提示**：情境卡未写出的条件不能当作已满足；不同角色的偏好不自动成为硬约束。
- **任务顺序**：读模拟任务书 → 标需求与来源 → 向资料库请求缺项 → 分类整理 → 说明缺项对后续比较的影响。
- **学习证据**：需求与信息缺口清单，每项写明来自哪里、影响哪个判断、由何种专业资料补充。

### S4-M02 比较方案与解释取舍

- **目标与内容**：从安全、耐久、适用、施工影响及经济等维度比较备选桥型或施工思路，学习定性比较与条件化建议。
- **误解提示**：一个总分不能掩盖未满足的必要条件；虚构权重和分值不是工程验证；成本最低不能单独决定结论。
- **任务顺序**：列备选 → 标明证据和缺项 → 比较各维度 → 改变一个偏好或条件 → 检查排序是否改变并解释。
- **学习证据**：备选比较表和有前提的建议，至少保留一项未采纳方案及理由，不编造精确造价或性能数值。

### S4-M03 核对巡检与监测信息

- **目标与内容**：结合模拟巡检、检测摘要和监测曲线检查来源、时间、单位、传感器状态及环境背景，练习异常信息核实。
- **误解提示**：单点突变、缺测或报警不自动证明结构风险；数据看似平稳也不证明各方面安全。
- **任务顺序**：先读数据说明 → 标异常与缺测 → 对齐位置和时间 → 比较其他资料 → 列出可支持的判断与待排查原因。
- **学习证据**：证据对照单，能区别数据质量问题、观测变化和原因假设；不制定实桥报警阈值或应急处置指令。

### S4-M04 养护讨论中的优先次序

- **目标与内容**：结合证据完整性、问题影响、交通干扰、资源与长期维护需求，讨论模拟任务的核实和养护优先次序。
- **误解提示**：外观最醒目的问题不必然最优先；缺少资料不等于风险为零；不能靠界面排序替代专业处置决策。
- **任务顺序**：读案例证据包 → 区分应先核实与可继续比较事项 → 提出次序 → 接收新增资料 → 修订并解释变化。
- **学习证据**：附条件的次序说明，指出需专业人员进一步评估的问题和可能改变排序的新证据。

### S4-M05 角色沟通与评审

- **目标与内容**：认识业主、设计、施工、养护等角色的信息需求与责任边界，练习把同一建议解释给不同听众。
- **误解提示**：表达自信不能弥补证据缺口；角色扮演不授予实际岗位职责；技术意见与正式决定需要区分。
- **任务顺序**：整理建议 → 面向两个角色各作说明 → 接受质询 → 引用证据回应 → 记录仍无法回答的问题与复核请求。
- **学习证据**：简短建议书、备选说明和问答记录，清楚区分当前建议、限制及必须进一步确认的事项。

**阶段项目与出口**：在虚构情境中提交建议书并答辩，包含需求、备选、证据链、取舍、限制和复核问题。没有唯一桥型或养护排序答案；按论证与证据评价。遗漏关键约束回到 M01，比较无依据回到 M02，误用数据回到 M03，忽视新增证据回到 M04；修订后以新资料答辩。通过后进入 S5 综合迁移。

## 6 S5 大师成就

**阶段目标**：在复杂案例中组织已有知识，面对新条件修订论证，并用可交互讲解帮助他人理解和纠错。安全耐久、全生命周期与数据应用议题参考 [3][4]。本阶段强调学习成果质量，不宣称学习者达到行业“大师”或专家资格。

**前置与诊断**：能完成 S4 的有条件建议，接受反证并修订结论。以过去的作品为入口，检查哪些结论依赖特定环境、资料或简化条件。

### S5-M01 复杂案例的系统复盘

- **目标与内容**：把需求、结构选择、建造过程、运营记录与维护安排放入同一时间线，寻找阶段间联系。
- **误解提示**：知道最终结果后容易把早期不确定性写成必然；复盘不能把未有证据的猜测写成事故原因。
- **任务顺序**：整理材料时间线 → 标当时可知信息 → 连接关键判断与证据 → 标出其他可能解释 → 提炼可迁移与不可迁移的经验。
- **学习证据**：带来源的复盘图和限制说明；涉及真实事件时只使用可公开核实资料，不自行归责。

### S5-M02 改变条件后的知识迁移

- **目标与内容**：面对交通需求、环境或维护条件变化，识别原建议中失效的前提，形成新的核实与比较步骤。
- **误解提示**：复制旧方案、只修改结论措辞不构成迁移；更换条件不意味着已有证据全部作废。
- **任务顺序**：接收新条件 → 标注受影响的原假设 → 保留仍有效证据 → 修订比较与建议 → 解释哪些问题需要重新验证。
- **学习证据**：前后版本对照，逐项说明保留、撤回、修改和新增验证事项。

### S5-M03 长期权衡与新方法评价

- **目标与内容**：围绕安全、耐久、韧性与可持续性提出长期问题，评价新材料、监测和数字化方法的用途、证据及限制。
- **误解提示**：技术新颖不等于适用；三维可视化不自动构成经验证的数字孪生；更多数据不自动产生可靠结论。
- **任务顺序**：选择一项方法说明 → 核对来源和应用前提 → 对照案例需求 → 列收益、成本与缺失证据 → 提出是否继续研究的理由。
- **学习证据**：方法评价卡，以定性问题和来源为主；涉及尚未核实的性能或减排数据时明确留空，不用精确数字制造确定性。

### S5-M04 证据质量与责任表达

- **目标与内容**：检查来源可信度、版本、适用范围和论证跳跃，练习表达不确定性、专业复核需要与公共安全责任。
- **误解提示**：“可能”不能代替证据；引用权威名称不意味着所有延伸结论都得到支持。
- **任务顺序**：审查一份含薄弱论证的案例 → 给结论标来源 → 找出越界推断 → 改写为有依据的陈述 → 接受同伴反驳。
- **学习证据**：结论与证据对应表，能解释为什么某结论应保留、弱化或撤回。

### S5-M05 制作并试教可交互微课

- **目标与内容**：把一个易错概念组织为学习目标、预测、操作、反馈和迁移练习，并用学习者反馈改进讲解。
- **误解提示**：画面精致、讲解流畅或同伴说“听懂了”不足以证明学会；不能通过提示直接泄露迁移题答案。
- **任务顺序**：选择误解 → 写一节短课脚本 → 配置视角和构件动作 → 请同伴先学后做陌生题 → 依据错误修订并再次试教。
- **学习证据**：微课脚本、可用的静态替代版、审校意见和前后修订记录。三维能力未实现时可先用分镜验证教学设计。

**阶段项目与出口**：形成综合案例包与一节可复用微课。案例包包括来源、假设、前后论证、待验证事项和反思；微课应让另一位学习者完成独立解释或迁移任务。评价重点是论证质量、迁移、边界与教学效果。迁移薄弱回到 M02，引用或责任表达不当回到 M04，只有演示没有学习证据回到 M05；完成再试教后归档为课程作品，不颁发专业资质证明。

## 7 统一课型与评价方法

### 7.1 一节课的基本顺序

1. **观察问题**：说明本课要回答什么，给出必要情境和术语，不先展示完整答案。
2. **作出预测**：允许文字、口述、选择或标注；保留原判断，以便后来比较。
3. **操作验证**：一次主要改变一个教学条件，提供重置、回看及静态对照。操作结果来自预设教学模型时明确说明。
4. **解释依据**：要求学习者指出构件、图示或资料中的证据；分别反馈知识问题与操作问题。
5. **迁移应用**：换视角、构件、桥型或情境，减少提示，检查能否独立解释。

失败反馈采用“指出不一致处 → 提供局部提示 → 返回对应视图或资料 → 再解释”的顺序。先给提示，仍需帮助时才展示完整示例答案；重试用等价新题，避免只记住上次选项。

### 7.2 通用学习评价量规

各阶段采用同一维度、不同难度的证据。建议用以下四档作形成性评价，不直接合成排名：

| 维度 | 0 尚未形成 | 1 需要提示 | 2 能独立完成 | 3 能迁移与反思 |
| --- | --- | --- | --- | --- |
| 概念与定位 | 关键构件或概念混淆 | 熟悉图中基本正确 | 陌生例中辨认并解释 | 比较差异并主动纠错 |
| 因果与关系 | 无依据或关系断裂 | 提示后连起部分关系 | 给出连贯解释 | 条件变化后修订解释 |
| 证据与表达 | 判断无法追溯 | 能引用部分材料 | 来源、观察与推测分明 | 核对冲突并评价证据 |
| 边界与反思 | 把示意当实桥结论 | 提醒后承认限制 | 主动说明条件与缺项 | 知道何时撤回或补证 |

建议阶段出口要求本阶段适用维度均达到 2；S1 的“关系”只要求构件作用及相邻联系，不能提前按受力分析要求评分。S5 还应在迁移与反思方面达到 3。以上为初始教学标准，须由教师试用校准，不是经验证的统一测量工具。

把概念示意当作安全证明、把推测写成观测事实、隐藏关键证据缺口属于必须先订正的问题，不能被其他高分抵消。未通过时指出具体模块和缺失证据，允许文字、口述或静态标注等价重试。记录学习作品和订正理由即可，点击次数、停留时长、动画完成率不能单独证明掌握。

## 8 课程脚本与配置建议

### 8.1 每课内容模板

课程作者可按以下字段先写脚本，再由开发者映射到配置。字段为建议内容规范，尚未全部进入现有类型。

| 字段组 | 必填内容 |
| --- | --- |
| 身份与版本 | `courseId`、`moduleId`、内容版本、标题、阶段、作者与审校状态 |
| 学习准备 | 适用对象、前置模块、诊断题、术语补充、建议时长 |
| 教学目标 | 1–3 个可观察目标、关键概念、常见误解、范围与简化条件 |
| 案例与资产 | 案例 ID、构件 ID、图示/模型版本、来源、授权及虚构说明 |
| 步骤 | `stepId`、问题、讲解、目标构件、场景意图、预测要求、反馈与完成条件 |
| 理解检查 | 题目、目标关联、可接受答案、理由、提示层级、重试题与回学模块 |
| 学习成果 | 作品模板、评价标准、阶段出口证据及教师复核项 |
| 替代与验证 | 文字/静态图、键盘路径、减少动画方案、内容与操作验收记录 |

建议 ID 使用稳定形式，如 `s1-m02-components`，步骤使用 `observe`、`predict`、`explain` 等有语义的标识；最终命名规则由内容契约统一。ID 不依赖显示名称、数组顺序或三维对象 UUID。修改内容版本时保留目标与评价变更说明。

### 8.2 教学动作与现有架构的对应

截至本版核对，仓库已有 `Course`、`LessonStep`、`BridgeComponent`、`SceneIntent` 的最小类型；`SceneIntent` 目前只有 `highlightIds`，构件类型仅覆盖示例桥面与桥墩。已实现点选/按钮选择、步骤讲解、高亮与重置。不能把本方案的完整课程目录、评价量规或以下扩展动作当作已可运行配置。

- **现有能力可复用**：步骤文本、`focusComponentIds`、高亮 ID、构件说明，用于首课观察与解释流程。
- **按首课需要补充**：完整主要构件语义、预设视角、显隐/隔离或单项拆解，以及一题带解释的理解检查。先扩展类型与校验，再编写相应内容。
- **后续按模块引入**：图模对应、剖切、传力路径、施工时间轴、热点记录、桥型比较和证据卡切换。每项明确输入、可重置状态及文字替代；受力路径采用审校后的概念内容，不生成工程计算结果。
- **暂不默认建设**：账号、云端成绩、学习行为上报、自动判定工程结论、复杂多用户协作。开放性解释先使用教师量规或示例自查，不能用关键词命中冒充理解判定。

内容放入规划的 `content/`，示例内容现位于 `src/demo/`；课程 UI 对应 `features/course-player`，三维呈现对应 `features/bridge-viewer`，后续理解检查对应预留的 `features/knowledge-check`。课程内容通过语义 ID 关联场景，不在讲解里直接操作 Mesh。动作应为有限、类型化的配置，禁止课程文件执行任意脚本。完整接口和目录边界以[技术方案第 4–5 节](TECHNICAL_PLAN.md)为准。

### 8.3 首课脚本示例

建议首课取 S1-M02 的子集“认识梁桥的桥面、主梁与桥墩”，只在模型已补充主梁并审校后使用该标题；当前小样可先验证桥面、桥墩的选择与讲解。

1. **目标**：指出三个目标构件，用自己的话说明作用，并解释桥面与主梁的区别。
2. **观察**：整体模型配无答案问题“车辆经过的部分在哪里，下面有哪些构件？”
3. **预测**：让学习者选择认为支承桥面的构件，并写一句理由。
4. **操作**：逐一聚焦和高亮；若遮挡影响理解，只选隔离或分层示意一种方式，提供完整静态对照图。
5. **解释**：恢复整体，要求连接名称、位置与作用；答错时引导比较两个构件的相邻关系。
6. **迁移**：换一个模型视角和构件颜色，独立重新定位并说明；另用一张陌生梁桥示意图排除位置记忆。
7. **出口**：提交三项构件标注与两句解释。教师检查是否真正区分桥面与主梁，以及示意简化是否造成新的误解。

## 9 教学审校与可访问性

### 9.1 内容制作与教师复核

建议流程为：目标与脚本 → 桥梁知识审校 → 资产映射 → 教学走查 → 小范围试教 → 修订发布。每课记录来源、改编说明、版本与审校人；人员未确定时标为“待审校”，不默认已完成专业审核。

教师复核至少检查：术语是否统一；所选桥型、连接与支承是否匹配；箭头与施工关键帧是否误导；可接受答案是否允许合理差异；反馈是否解释原因；迁移题是否真正改变条件；文字替代能否完成同一学习目标。受力、施工、病害和监测情境优先安排相应知识审校，软件测试通过不能替代内容审核。

### 9.2 让操作门槛不遮蔽学习目标

- 构件名称、讲解、题目与反馈提供 DOM 文本；三维点选配构件列表或按钮，主要操作可键盘完成。
- 颜色同时配名称、编号、线型或边框；不得只按红绿区分答案或异常。
- 连续相机运动和动画可暂停、跳过或减弱；时间轴拖拽配关键帧按钮，保持回看与重置结果一致。
- 准备静态视图和文字描述；WebGL 不可用时保留完整核心学习路径，而不只是错误提示。新增替代版须与三维版共同审校。
- 字号、标签密度、触控区域和阅读长度分别在目标设备及投屏条件下检查；观察与表达困难允许等价作答方式。

学习作品默认可以在课堂或本地完成，不要求收集身份、成绩和完整操作轨迹。以后确需保存个人学习数据，应另行明确必要性、授权、保留期限和访问范围。

## 10 首轮试点与课程扩展

本方案是五阶段内容地图，不要求同时建设 25 个模块。建议依次完成三段有明确出口的试点。

### 10.1 试点 A 先验证构件识别闭环

- **范围**：S1-M02 子集及 S1-M04 必要方位补充；一座教学梁桥、少量目标构件、一项主动操作和一题陌生图迁移。
- **准备**：确定目标学习者与内容审校人；补齐模型的必要构造和稳定 ID；写好正确解释、常见错误、提示与静态版。
- **观察**：学习者能否独立找到构件、说清作用；错误来自知识、遮挡、名称还是控件；改变视角后是否仍能识别。
- **出口**：关键知识错误已订正，流程可完成，替代路径有效，教师能依据作品判断掌握。未达到时先改脚本与模型，不增加桥型或特效。

### 10.2 试点 B 再验证概念解释

- **依赖**：试点 A 的构件和讲解稳定。
- **范围**：S2-M03 的梁桥传力路径，补充 S2-M01 必要作用概念；一次只选一个作用情境。
- **新增能力**：经审校的箭头或顺序高亮、预测与解释反馈、简化条件说明；不同时加入多种桥型和物理计算。
- **出口**：学习者在新作用位置下能解释连续路径，并说明示意不能支持的结论；若只会跟随动画，修改问题与反馈后再试。

### 10.3 试点 C 验证观察与证据记录

- **依赖**：试点 A/B 的构件、作用与边界知识；先补充 S3-M04 必要细部内容。
- **范围**：S3-M05 的一个局部虚拟巡检案例，使用少量热点、图片和文字证据，不先建设整桥巡检系统。
- **新增能力**：位置关联、证据卡、记录模板和教师量规；用可公开或虚构资料，避免未经授权的实桥数据。
- **出口**：同伴能按记录找到同一位置，记录区分观察与原因假设，学习者会请求缺失资料。只有定位没有解释时继续完善教学任务。

### 10.4 后续扩展的决策依据

三个试点逐步通过后，再补齐 S1/S2 基础模块、扩展 S3 构造与施工，最后制作 S4 方案评审及 S5 综合课题。每次新增模块都要回答：前置能力是否具备，模型与资料是否可用，是否能复用已有动作，谁审校，怎样证明学习效果。

首批任务可拆为：首课脚本与答案依据、构件模型与映射、必要动作与替代入口、理解检查与反馈、教学试用与订正五个工作项。每项附模块 ID、学习目标、输入资产、验收作品和依赖，沿用仓库的 Issue/PR 流程。内容修订与实现分别记录；完成一个技术功能不自动标记对应模块“已开课”。

试教记录重点保留代表性误解、提示依赖、迁移作品与教师修改意见。若比较教学版本，应说明学习者基础、任务与使用条件，不能凭少量反馈宣称普遍有效。正式排课、评价阈值和后续开发周期均在试点后校准。
