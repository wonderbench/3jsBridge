# 开发说明

## 内容与渲染边界

`src/domain/teaching.ts` 不依赖 React、Three.js 或浏览器 API。`src/demo/introCourse.ts` 提供本地示例，加载时校验步骤、构件 ID 和高亮引用。它不是针对不可信外部 JSON 的完整运行时 schema；接入外部内容时需要额外验证。

`componentId` 是教学层与渲染层的稳定映射键。不要依赖自动生成的 Mesh 名称。当前几何体映射在 `BridgeViewer.tsx`；引入真实模型时应建立独立资产映射与对应测试。

应用状态保留在 `App`：步骤变化清除旧选择，重置恢复首步骤、清除选择并重新建立相机。暂不引入状态库、网络层或持久化。`sceneIntent.highlightIds` 是当前支持的最小场景意图；相机预设、可见性和演示播放属于后续实现。

## 人工验收

1. 启动应用，确认三维模型与中文教学文案显示。
2. 拖动旋转、滚轮缩放；确认操作仅影响观察视角。
3. 点击模型构件，确认高亮与对应说明；点击空白取消选择。
4. 使用构件按钮重复选择，确认按钮状态与文字一致。
5. 前后切换三步课程，确认边界按钮禁用，步骤高亮与内容一致。
6. 连续点击重置，确认恢复首步骤、默认视角和未选择状态。
7. 使用 Tab/Enter 操作按钮，不依赖鼠标拾取也能阅读课程。
8. 在窄屏检查文字、场景、按钮无水平溢出。
9. 无 WebGL 时检查文字课程及构件按钮仍可使用。

## 验证范围

本次已通过代码检查、类型检查、7 项自动化测试和生产构建。受执行环境限制，Chromium 未能启动，因此真实浏览器冒烟测试与真机验证尚未执行；以下人工验收清单仍待完成。

自动化测试覆盖内容引用、重复 ID、空课程、按钮选择、步骤边界与重复重置。真实模型拾取、相机交互、WebGL 兼容性仍需浏览器验证。没有后端、账号、学生数据采集、资源上传、工程求解器或部署配置。

基础 CI 只执行依赖安装和检查，不部署网站。安装依赖以 package-lock.json 为准；升级后重新执行全部检查和浏览器验收。
